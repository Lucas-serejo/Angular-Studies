## Password Generator

The **Password Generator** project is a study effort focused on understanding and applying Angular concepts, particularly the **template-driven forms** approach using `ngModel`. This project demonstrates how to bind user input to the component logic seamlessly, enabling dynamic and reactive form handling without the need for extensive configuration.

### Key Features:
- **Template-Driven Forms**: Utilizes `ngModel` for two-way data binding, simplifying form management.
- **Dynamic Password Generation**: Generates secure passwords based on user-defined criteria.
- **Angular Best Practices**: Implements clean and modular code to reinforce Angular development principles.
